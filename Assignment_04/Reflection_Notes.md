# Reflection notes

The assignment explicitly says the reflection must be written in the student's own words without AI writing it. These points can help Devon write his own 100–150 words after reviewing the script and the recorded results:

- The example prompt in the brief used `CustomerID` and `Region`, but the actual CSV has `Customer` and no region field. How did that difference affect the prompt or cleaning plan?
- The script keeps questionable rows in a separate review file. Explain whether this approach makes sense for missing products, missing quantities and unusually high quantities.
- What did the before-and-after summaries or tests show, and what would Devon check with the data owner before making permanent changes?
- What information about column names and assumptions would make a future prompt more precise?
