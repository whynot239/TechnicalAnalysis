# Technical Analysis in R

BDA 400 | Devon Wells

This repository contains the course's R exercises and the three-stage technical-analysis project. The assignment folders include source files, reports, test output and supporting evidence.

- `Assignment_02`: portfolio data import and descriptive statistics.
- `Assignment_03`: outlier flagging function and tests.
- `Assignment_04`: sales-data cleaning and quality checks.
- `Assignment_05`: base R technical indicators and tests.
- `Assignment_06`: Shiny dashboard and browser screenshot.

Run the scripts from their own assignment folder. The stock-data examples require an internet connection and the packages listed in the individual reports. AI assistance and the scope of actual checks are documented in each folder.

The materials are drafts for review. Some course-specific personal verification, the Assignment 4 personal reflection and RStudio setup evidence remain outstanding.
